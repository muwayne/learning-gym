多头切分与 Pre-LN Block

A1·S02 配套演示 · toy 设定：L=3 个 token，d=4 维，H=2 个头，每头 d_h = 4/2 = 2 维 · W_V 与 W_O 用单位阵便于看数

一 · 切头切的是"产出"，不是"原料"

W_Q 的每一列都吃进 X 的全部 4 维——所谓"头 0 的 2 维"，是投影产出的 2 列（蓝框）， 不是输入 X 的前 2 个特征。所以每个头看得到全部输入信息，只是各自在自己学出来的低维子空间里打分。

二 · 流水线：一份输入，两张独立的注意力地图

列颜色：头 0 的维度　头 1 的维度
每个头独立算自己的 S→P→O（缩放除的是每头维度的 √d_h=√2，不是整体的 √d）。 注意两张 P 的样子完全不同：头 0 尖锐（各看各的近亲），头 1 平缓——同一句话，两套"谁该看谁"的判断并行发生。这就是多头多买到的东西。
拼回：把 O⁰ 和 O¹ 按列并排接起来 → 乘 W_O 混合一次（此处单位阵，输出=拼接结果）。
