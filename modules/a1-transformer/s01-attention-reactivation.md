## ① 上手：三个对象与一个公式

一句话重述三个对象：

- **Q（query）**：我现在想找什么；
- **K（key）**：每个位置能提供什么索引；
- **V（value）**：被关注后真正取回的内容。

公式与逐步 shape（单头，无 batch）：

```text
X ∈ R^{L×d}                     L 个 token，每个 d 维
Q = X·WQ, K = X·WK, V = X·WV    仍是 L×d
S = Q·K^T / √d                  L×L：每行是一个 query 对所有位置的匹配分
P = softmax(S, 按行)            L×L：每行和为 1
O = P·V                         L×d：每行是对 V 的加权平均
```

除以 √d 的原因：独立同分布分量的点积方差随 d 线性增长，d 大时 logits 过大、softmax 进入饱和区（梯度≈0）。缩放把分数拉回温和区间。

**已算样例**（照着核对格式，L=2、d=2，取 WQ=WK=WV=I 方便心算）：

```text
X  = [[1,0],
      [0,1]]
S  = X·X^T = [[1,0],[0,1]]
S/√2 ≈ [[0.71,0],[0,0.71]]
P 第 1 行 = softmax([0.71, 0]) = [e^0.71, e^0]/Σ ≈ [2.03,1]/3.03 ≈ [0.67, 0.33]
O 第 1 行 = 0.67·[1,0] + 0.33·[0,1] = [0.67, 0.33]
（第 2 行对称：P=[0.33,0.67]，O=[0.33,0.67]）
```

**现场演示**：[QKV 机器人检索全流程](demos/qkv-robot-walkthrough.html)。依次查看输入特征、固定投影 Q/K/V、匹配分数、softmax 权重与加权位置输出。示例用 cross-attention：Q 来自指令，K/V 来自物体；本课 self-attention 则三者同源，后续计算相同。特征与投影均为教学构造，未训练模型；演示的是一次 forward pass，输出只是加权位置，不能直接当作机器人控制指令。

## ② 手算自检（不回看上文）

给定 L=3、d=2，WQ=WK=WV=I：

```text
X = [[2,0],
     [0,2],
     [1,1]]
```

在纸上写出：S（3×3）→ S/√2 → 每行 softmax（保留两位小数）→ O（3×2）。答案在文末折叠段，**先算再看**。

## ③ 追问（预埋卡点，先自答一句，再让 AI 判）

1. WQ 和 WK 为什么不能共用一个矩阵？（提示：那样 S 被迫对称——"A 关注 B"必然等于"B 关注 A"，合理吗？）
2. K 和 V 为什么要分开？（提示：字典的检索键和存储值是同一个东西吗？）
3. 去掉 /√d，把 d 从 4 加到 512，softmax 每行会发生什么？梯度呢？
4. 现在这个 attention 对 token 顺序敏感吗？（提示：置换 X 的行，输出如何变？position 信息此刻在哪里——答案：还没有，S02 引入）
5. 1 个 d=64 的头和 8 个 d=8 的头，QKV 参数量一样吗？表达力差在哪？
6. L 翻倍，计算量和显存各乘几？哪个中间量是罪魁？

其中至少 1 条 AI 的回答按 [rubric](../../ai-review-rubric.md) 记 claim audit（AI 说得流利 ≠ 说得对，逼它给出机制或反例）。

## ④ 动手：50 行单头 attention（P-T-I-E）

**先锁预测**（写进 log 的①段再动手）：

- P1：实现结果与②手算在 ±0.02 内一致。若不一致，先猜最可能错在哪一步；
- P2：去掉 /√d 且 d=256（随机 X）时，softmax 每行最大概率会 >0.99 还是变化不大？
- P3：mask 掉位置 (0,2) 后，第 0 行概率和还是 1 吗？O 的第 0 行变不变？

**实现约定**：

- numpy、≤50 行，签名 `attention(X, WQ, WK, WV, mask=None) -> (O, P)`；
- 核心函数**必须自己写**（A 亲手 / B 口述驾驶 / C 填空抓错均可，见课表「亲手的三种合法模式」）；AI 只允许搭 assert/画图 harness（这条分工写进 log）；
- 验收 assert：② 的手算数值 · P 每行和=1 · 被 mask 位置 P≈0。

**干预**（单变量，二选一）：

- I-a：去掉缩放，扫 d ∈ {4, 64, 256}，画每行 softmax 熵随 d 的曲线；
- I-b：WV=I 与 WV=随机 对照，看输出方差来自"关注谁"还是"取回什么"。

**Explain**：逐条判 P1–P3，写 surprise；没有 surprise 就写"最接近翻车的一步"。
