先钉住 Zero-Shot 的含义

在这条文献线里，Zero-Shot RL 的流程是：先在给定环境中预训练；新 reward / goal / demonstration 到来后，保持网络固定，通过简单任务编码直接调用已学策略。可复用的是这个环境中学到的动力学与行为能力。

Behavioral Foundation Model（BFM，行为基础模型） 在本章指预训练后可被多种任务提示调用的行为模型。FB 描述学习表示与控制的方法，BFM 描述模型的能力与接口；一个可执行系统还包含 actor、观测接口与控制器。

可以把它看成“可索引的策略族 + task description 到 z 的翻译规则”：任务提示进入模型，行为在动力学中闭环执行。据 Yuan et al. 的 2025 年 BFM 综述 §I-C，behavior(al) foundation model 这一术语首次出现在 FB-IL，即 Fast Imitation via Behavior Foundation Models（ICLR 2024）。

2023 论文还区分：显式给出 reward function 是严格的 zero-shot；用少量 (state, reward) 样本估计任务向量，属于 few-shot task specification、zero-planning。课程沿用文献的 Zero-Shot RL 名称，同时保留这个区别。定义：2023 §2

阅读后续方法时，可以沿着四个问题理解它的“即用能力”：任务由什么数据描述，网络哪些部分更新，latent 怎样得到，执行前做了什么搜索。

1 · SR：一张足迹表怎样复用到不同任务

1.1 五格走廊与时间合同

【例】状态是 0, 1, 2, 3, 4；动作是 left / stay / right；撞墙留在原格；默认折扣 γ=0.5\gamma=0.5。这是 continuing task：过程可以一直继续，到达目标后仍可继续得奖励。

先从 current-state reward 讲起：当前在 sts_t 就收到 r(st)r(s_t)。

M0π(s,j)=𝔼π[∑t=0∞γt𝟏{st=j}∣s0=s],V0π(s)=∑jM0π(s,j)r(j).M_0^\pi(s,j)=\mathbb{E}_\pi\left[\sum_{t=0}^{\infty}\gamma^t\mathbf{1}\{s_t=j\}\mid s_0=s\right],\qquad V_0^\pi(s)=\sum_j M_0^\pi(s,j)r(j).

M0M_0 的行是起点，列是未来访问的状态。下标 0 提醒它包括当前状态。它是 discounted occupancy（折扣访问量）：将各时刻的访问按折扣累加，每行之和为 1/(1−γ)1/(1-\gamma)。默认值下行和为 2；乘以 1−γ1-\gamma 才得到归一化的访问分布。

1.3 表是怎么学出来的

有环境转移模型时：M0π=(I−γPπ)−1M_0^\pi=(I-\gamma P_\pi)^{-1}。只有 sampled transitions 时，SR 同样可以用 TD 更新一行：

M0π(s,⋅)←M0π(s,⋅)+α[es+γM0π(s′,⋅)−M0π(s,⋅)].M_0^\pi(s,\cdot)\leftarrow M_0^\pi(s,\cdot)+\alpha\left[e_s+\gamma M_0^\pi(s',\cdot)-M_0^\pi(s,\cdot)\right].

ese_s 是当前状态的 one-hot；下一步 s′s' 来自该策略。普通价值 TD 更新一个数，SR 的 TD 更新一个“所有终点的向量”。后面的 FB 仍使用这个递推思想，只是压缩了向量并同时处理一族策略。

在真实训练里，reward relabeling 将同一条 transition 用于不同任务。它复用已有的动力学经验，因而效果取决于这些经验覆盖了哪些状态与动作。

2 · SF、GPI 与 USFA：压缩什么，改进什么

2.1 SF 把“未来每个状态”换成“未来每个特征”

Feature map φ(s)∈ℝd\varphi(s)\in\mathbb{R}^d 将状态映射到特征。若奖励可写为 r(s)=φ(s)⊤wr(s)=\varphi(s)^\top w，则 current-state 版 SF 为：

ψ0π(s)=𝔼π[∑t≥0γtφ(st)∣s0=s],V0π(s)=ψ0π(s)⊤w.\psi_0^\pi(s)=\mathbb{E}_\pi\left[\sum_{t\ge0}\gamma^t\varphi(s_t)\mid s_0=s\right],\qquad V_0^\pi(s)=\psi_0^\pi(s)^\top w.

【例】选两个特征：φ(s)=[𝟏{s∈{3,4}},𝟏{s∈{0,1}}]\varphi(s)=[\mathbf{1}\{s\in\{3,4\}\},\mathbf{1}\{s\in\{0,1\}\}]，即右侧、左侧。对 πR\pi_R，从 0 出发的 SF 是 [0.25, 1.5]，从 2 出发是 [1, 0]，从 4 出发是 [2, 0]。

右侧奖励可以用 w=[1,0]w=[1,0] 表示。格 2 的特征则是 [0,0]，与任意 ww 点积都为零；“仅在格 2 得 1 分”落在这组特征的 span 之外。这是 reward representation error：任务所需的区别在压缩时丢失了。

特征既可以由人设计，也可以来自自编码、contrastive learning、Laplacian 或其他 learned representation。这让 SF 与多种表示学习方法相连。Barreto et al. 2017

2.2 从 reward samples 到权重

用数据分布 ρ\rho 做最小二乘：

Cφ=𝔼ρ[φφ⊤],wr=Cφ−1𝔼ρ[φr].C_\varphi=\mathbb{E}_\rho[\varphi\varphi^\top],\qquad w_r=C_\varphi^{-1}\mathbb{E}_\rho[\varphi r].

奇异时使用 pseudoinverse 或 regularization。CφC_\varphi 是由原始特征外积平均得到的 second-moment matrix。r̂(s)=φ(s)⊤wr\hat r(s)=\varphi(s)^\top w_r 是该表示空间中、按 ρ 加权最接近原奖励的函数；当原奖励位于 feature span 内时，重构可以精确。

在真实训练里，“encoder 重建准确”与“task reward 能线性表达”是不同合同。原始低维坐标足够重建状态，却可能不足以线性表达“只在某个小区域奖励”。

2.3 GPI：逐步重选怎样改进策略

Generalized Policy Improvement（GPI） 用一组旧策略在同一个新奖励下的 action values：

πGPI(s)∈arg⁡maxamaxiQrπi(s,a).\pi_{\mathrm{GPI}}(s)\in\arg\max_a\max_i Q_r^{\pi_i}(s,a).

关键是：Qrπi(s,a)Q_r^{\pi_i}(s,a) 允许第一步先做任意动作 aa，之后才跟随旧策略 πi\pi_i。执行 GPI 时，每一步都会重新选择，所以它可以组合出旧策略没有完整执行过的行为。在精确 action-value 等条件下，GPI 的表现至少达到来源策略的上包络。

【例】仍用 current-state reward，目标为格 2，旧策略只有 πR\pi_R 和 πL\pi_L。先展开 QrπR(2,stay)Q_r^{\pi_R}(2,\mathrm{stay})：只指定第一步 stay，之后一直跟随旧策略 πR。

t = 1 格 2 开始跟随 πR，向右 0.5 × 1 = 0.5
t = 2 格 3 πR 继续向右 0.25 × 0 = 0

QrπR(2,stay)=r(2)+γVrπR(2)=1+0.5×1=1.5.Q_r^{\pi_R}(2,\mathrm{stay})=r(2)+\gamma V_r^{\pi_R}(2)=1+0.5\times1=1.5.

后面的 0.5 来自晚一步在格 2 再得到的奖励 1，乘上折扣 0.5。stay 的作用是让下一时刻仍在格 2。r(2)=1r(2)=1 是当前奖励，VrπR(2)=1V_r^{\pi_R}(2)=1 是之后一直向右的总回报；在这条旧策略下，两者数值恰好相等。跟随 πL 得到同样的 1.5。

第一步 right 后继续 πR，或第一步 left 后继续 πL，都只拿到起点的奖励 1；若第一步 right 后改跟 πL，则会晚两步再经过格 2，得到 1+0.52=1.251+0.5^2=1.25。三个动作各自的最好旧策略评分为：left = 1.25，stay = 1.5，right = 1.25，所以 GPI 选 stay。

执行 GPI 时，每一步都重新用旧策略评分，再选当前动作。 下一步仍在格 2，GPI 又比较三个动作，再选 stay，于是实际执行 stay → stay → stay → …，新策略价值为 1+0.5+0.25+⋯=21+0.5+0.25+\cdots=2。

2.4 USFA 向一族策略迈进一步

3 · Touati & Ollivier 2021：FB 到底承诺了什么

Learning One Representation to Optimize All Rewards（NeurIPS 2021） 提出 FB。进入 2023 前，应吃透本节的对象、代数与假设；2021 的完整测度论证明可按需回查，无需先从头精读。原论文

3.1 从表到 Successor Measure

在连续空间里，用区域代替表格的一列。Successor measure Mπ(s,a,X)M^\pi(s,a,X) 表示未来访问某个区域 XX 的折扣量。

从这里开始采用 2023 的 next-state reward convention：先做 ata_t，到 st+1s_{t+1}，再收到 r(st+1)r(s_{t+1})。

Mπ(s,a,X)=𝔼[∑t≥0γt𝟏{st+1∈X}∣s0=s,a0=a,π].M^\pi(s,a,X)=\mathbb{E}\left[\sum_{t\ge0}\gamma^t\mathbf{1}\{s_{t+1}\in X\}\mid s_0=s,a_0=a,\pi\right].

Qrπ(s,a)=∫Mπ(s,a,ds+)r(s+).Q_r^\pi(s,a)=\int M^\pi(s,a,\mathrm{d}s^+)\,r(s^+).

两个时间合同的桥梁是：五格确定性例子中，若第一步到 f(s,a)f(s,a)，则 next-state 的 state-action occupancy 行等于 M0π(f(s,a),⋅)M_0^\pi(f(s,a),\cdot)。先找到第一步到达的格子，再取那一行 SR，就完成了索引转换。2021 与 2023 的 TD 正项也因此存在索引差别；本讲义后半统一使用 2023 写法。

3.2 F、B、ρ 与 z 的分工

FB 用低秩模型近似一族策略的 successor measure：

Mπz(s,a,ds+)≈F(s,a,z)⊤B(s+)ρ(ds+),πz(s)∈arg⁡maxaF(s,a,z)⊤z.M^{\pi_z}(s,a,\mathrm{d}s^+)\approx F(s,a,z)^\top B(s^+)\,\rho(\mathrm{d}s^+),\qquad \pi_z(s)\in\arg\max_a F(s,a,z)^\top z.

3.6 任务坐标、奖励投影与旋转自由度

对给定的 BB，可以沿着一条链理解任务坐标：先将 reward-weighted state embeddings 平均得到 zrz_r；再用二阶矩将它换算成普通回归系数 wrw_r；最后重构模型能表达的奖励 r̂\hat r。同时，zrz_r 还是条件策略的输入。

当 CB=IC_B=I 时，简化为 r̂=B⊤zr\hat r=B^\top z_r。从 measure 分解得到的价值公式仍为 Qrπz≈F(s,a,z)⊤zrQ_r^{\pi_z}\approx F(s,a,z)^\top z_r；正交化进一步简化坐标换算，并改善数值条件。

正交化固定了尺度，仍保留旋转自由度。若 RR 是 orthogonal matrix，同时令 B′=RBB'=RB、z′=Rzz'=Rz，并重参数化 forward map 使 F′(s,a,Rz)=RF(s,a,z)F'(s,a,Rz)=RF(s,a,z)，则两个点积保持不变。actor 的条件端也作相应坐标变换，就得到同一行为的另一种表示。

因此，理解 latent 最直接的方式是用已知 goal / reward 探测方向，看它实际控制什么行为。跨运行比较表示时，也应比较子空间或可执行任务，而非逐维对齐名称。

固定特征下，task encoding 对奖励是线性的：zr1+r2=zr1+zr2z_{r_1+r_2}=z_{r_1}+z_{r_2}。逻辑“且”若由乘积奖励表达，就对这个新奖励重新编码。正数放大奖励保留理想最优策略；实际 actor 常把 z 归一化到训练时的球面尺度，具体效果取决于训练分布。零向量需要单独定义处理方式，例如保留零输入并使用固定的动作平局规则。

4 · FB 怎样在没有下游任务奖励时训练

4.1 Bellman 递推是学习信号

next-state convention 下：

Mπz(s,a,X)=P(X∣s,a)+γ𝔼s′,a′∼πz[Mπz(s′,a′,X)].M^{\pi_z}(s,a,X)=P(X\mid s,a)+\gamma\mathbb{E}_{s',a'\sim\pi_z}[M^{\pi_z}(s',a',X)].

第一项是下一步真实转移，第二项是之后的折扣未来。Transitions 本身就提供了学习未来访问的监督信号。 这让具体 downstream reward 可以延后给出，而长期预测与控制仍在预训练中学习。

4.2 读懂 loss 中的两类终点

简化到一个 FF 网络，主 loss 写成：

ℒFB=𝔼z,(s,a,s′),s+[(F(s,a,z)⊤B(s+)−γF‾(s′,πz(s′),z)⊤B‾(s+))2]−2𝔼z,(s,a,s′)[F(s,a,z)⊤B(s′)].\mathcal{L}_{\mathrm{FB}}=\mathbb{E}_{z,(s,a,s'),s^+}\left[\left(F(s,a,z)^\top B(s^+)-\gamma\bar F(s',\pi_z(s'),z)^\top\bar B(s^+)\right)^2\right]-2\mathbb{E}_{z,(s,a,s')}[F(s,a,z)^\top B(s')].

其中 (s,a,s') 是真实 transition；s+s^+ 是从 replay state marginal 独立抽样的查询终点；横线是 non-trainable target，参数通常用 Polyak averaging 更新。s′ 提供已观察到的一步，s⁺ 指定要预测访问量的位置。

负的第二项锚定真实到达的下一状态；平方项约束整个未来访问模型的递推一致性。二者配合，将局部转移与整张足迹表接起来。这个展开来自 measure Bellman residual，并省掉了与可训练参数无关的常数。

4.3 Actor 与 B 的尺度

连续动作中，用 actor 近似 greedy action：

ℒactor=−𝔼s,z[F(s,π(s,z),z)⊤z].\mathcal{L}_{\mathrm{actor}}=-\mathbb{E}_{s,z}[F(s,\pi(s,z),z)^\top z].

actor update 时通常固定 critic / representation 参数，让梯度沿动作路径从 F 回到 actor；target branch 则 stop-gradient。连续控制实现还会加入 double networks、clipped estimates 或 smoothing，具体组合见 §5 的论文导航。

正交化约束为 𝔼ρ[BB⊤]≈I\mathbb{E}_\rho[BB^\top]\approx I。分解有 gauge freedom：可同时变换 F 和 B 而保持点积。正交化帮助控制尺度、改善条件数，并让不同表示维度得到充分使用；坐标的旋转自由度仍如 §3.6 所述。

训练时不断抽取 z，让共享网络接触一族任务。实际泛化来自任务抽样覆盖、transition 覆盖以及网络在这些样本间学到的共享结构。

4.4 一次 batch 的形状与阶段

设 batch size 为 NN、latent dimension 为 dd。F(s,a,z)、B(s+)、z 都是 N × d；成对点积得到 N 个 scalar。用 all-pairs 训练时，FB⊤F B^\top 得到 N × N 的起点—终点分数矩阵：每个起点都与每个查询终点配对。

4.5 Bellman、TD 与 TD3 是三个不同对象

Bellman equation 是长期量必须满足的关系；Temporal Difference（TD）learning 用 sampled transition 和 bootstrapped future estimate 学这个关系；TD3 是具体的连续控制算法，名字来自 Twin Delayed DDPG，而不是 Temporal Difference 的缩写。TD3 critic 的训练确实使用 TD。

4.6 一条 transition 为什么能配多个 z

(s,a,s') 记录在该环境中执行 a 后发生了什么。只要 dynamics 相同，这个一步转移就能服务不同任务；从下一状态开始，target action 再由各自的条件策略 πz\pi_z 生成。这就是复用数据的 off-policy 路径，效果取决于 state-action coverage。

再把 s⁺ 想成一个“奖励探测点”。 在离散走廊中，固定一个终点 j，定义“到达 j 得 1 分”的奖励 rj(s′)=𝟏{s′=j}r_j(s')=\mathbf1\{s'=j\}。对同一个给定策略 πz：

Qjπz(s,a)=Mπz(s,a,{j})=𝔼[𝟏{s′=j}+γQjπz(s′,πz(s′))].Q_j^{\pi_z}(s,a)=M^{\pi_z}(s,a,\{j\})=\mathbb{E}\left[\mathbf1\{s'=j\}+\gamma Q_j^{\pi_z}(s',\pi_z(s'))\right].

于是，足迹表的每一列都在回答一个点奖励的价值问题。学习整张表，就相当于对给定 πz 并行评估许多个这样的奖励。 FB 把这些列压进共享的 F / B：ρ(j)F(s,a,z)⊤B(j)\rho(j)F(s,a,z)^\top B(j) 近似上面的 Q；点积本身则是除过 ρ(j) 的 density。抽取不同 s⁺，就是查询这张表的不同列。

这也说明为什么 s⁺ 要独立采样：真实 s′ 告诉模型这一步到了哪里，查询终点 s⁺ 让模型学习“从这一步出发，对其他终点的未来访问量”。连续空间中，用目标区域的指示奖励可得到同样的 Bellman 方程直觉。

ERFB：为何专家状态直接取平均

用最简单的 empirical-reward encoding 建立直觉：

zτ=1|τ|∑s∈τB(s).z_\tau=\frac{1}{|\tau|}\sum_{s\in\tau}B(s).

记专家 states 的经验分布为 ρe\rho_e。在 support 充分时，为它设置相对训练分布的奖励 r(s)=ρe(s)/ρ(s)r(s)=\rho_e(s)/\rho(s)，代入 FB 推断：

z=𝔼ρ[B(s)ρe(s)ρ(s)]=𝔼ρe[B(s)].z=\mathbb{E}_\rho\left[B(s)\frac{\rho_e(s)}{\rho(s)}\right]=\mathbb{E}_{\rho_e}[B(s)].

ρ 被约掉后，只需对专家状态的 B 求平均，就得到任务编码。多条示范时，论文先在每条 trajectory 内平均，再将 trajectories 等权平均。

RERFB 使用有界奖励 ρe/(ρ+ρe)\rho_e/(\rho+\rho_e)。记 μe=𝔼ρe[B]\mu_e=\mathbb{E}_{\rho_e}[B]、Ce=𝔼ρe[BB⊤]C_e=\mathbb{E}_{\rho_e}[BB^\top]，论文的回归式推断为：

zRER=CB(CB+Ce)−1μe.z_{\mathrm{RER}}=C_B(C_B+C_e)^{-1}\mu_e.

它使用的仍是未中心化二阶矩。这个回归式推断将有界奖励映入有限维任务空间，提供另一种近似选择 z 的方式。见 FB-IL §4.2、式 (8)–(9)。

整段 average 描述“希望多访问哪些状态”。轨迹 0→1→2 与 2→1→0 的 average 一样，因为二者有相同的状态计数。要进一步表达“何时访问”，就要在编码中加入时间或局部参考。

局部 tracking 可以随时间滚动未来窗口，生成 ztz_t，每一步重算并闭环执行。它把“接下来希望看到哪些状态”交给策略；姿态表示、速度与窗口定义共同决定跟踪效果。

固定奖励为什么可能只复制最常见的姿态

【例】专家 60% 的时间在格 2、40% 在格 3；训练 reference distribution 均匀。ERFB 对应的 reward 是 [0,0,3,2,0]。如果这些 occupancy 都可实现，匹配专家得到的平均 reward 是 0.6×3 + 0.4×2 = 2.6，全部待在格 2 则是 3。最大化一个固定 imitation reward，可能更偏爱模式集中的行为，而不是原样匹配专家比例。

这就引出另外两类目标：GAIL 式方法让 discriminator 随当前 policy distribution 更新；FB-IL 的 FM / DM 路线则利用 successor representation 衡量与专家未来的差别。它们都试图让优化目标更直接地反映分布匹配。GAIL 原论文

对专家与 reference states 等先验二分类，最优 D*(s)=ρe(s)/(ρe(s)+ρ(s))D^*(s)=\rho_e(s)/(\rho_e(s)+\rho(s))，其 odds D*/(1−D*)=ρe/ρD^*/(1-D^*)=\rho_e/\rho。这解释了 RER / ER reward 的联系。若用当前 policy替代 reference，分母便随 policy 改变，形成动态更新的 imitation signal。

FM / DM 与 GOALFB 保留的信息不同

FMFB 将专家每个起点的未来特征序列，与模型预测的 policy-conditioned 未来对齐。一般形式涉及 CBF(st,z)C_BF(s_t,z) 与 ∑kγkB(st+k+1)\sum_k\gamma^k B(s_{t+k+1})；F(st,z)F(s_t,z) 在这里表示对 actor action 平均后的 forward embedding。它利用起点—后继关系，保留的信息多于整段 B 平均。DMFB 与 BBELLFB 则分别通过分布距离或 Bellman residual 构造推断目标。

【例】走廊巡逻反复经过格 3，有时要求 left、有时要求 right。只观察位置时，策略在同一输入上遇到了两种动作要求；加入 direction / phase / history，就能区分这两个阶段。真实机器人 state 中的速度，也能承担这种区分作用。

GOALFB 让 ztz_t 随参考未来状态改变，把 phase 通过 prompt 带进来。它依赖给定 reference；示范结束后的延续行为另需定义。Meta Motivo / BFM-Zero 的 rolling-window encoding 继续使用这种随时间更新任务提示的接口，并配上各自的训练方法。

9 · 接回 IL、RL 与 VLA：三个分类轴

9.1 数据来源、学习目标与模型接口

Imitation Learning（IL） 表示从示范中学习行为，Behavioral Cloning（BC） 是其中直接拟合 action 的一类方法。示范可以来自人、planner、RL expert 或 privileged teacher；“是谁产生数据”与“怎样使用监督”是不同问题。

Teleoperation 通常能提供目标机器人对应的 observation-action labels；ego video / mocap 则提供人的运动观测，需要 retargeting、inverse dynamics、latent action 等路径接到机器人。同一段 mocap 可以用于 reward-based tracking，也可以在取得合适 action labels 后用于 BC：关键在于如何使用这些数据。

Diffusion / flow policy 也常用于 BC，分别通过 denoising、flow matching 等目标拟合示范动作分布。VLA 描述 vision / language / action 的模型接口，可以经过 IL 预训练、RL 后训练等多个阶段；世界模型则另有视频或状态预测目标。区分模型接口与训练 objective，就能逐阶段读懂一个混合系统。基础讲义：expressive policy

9.2 DAgger、teacher–student 与 RL 的边界

DAgger（Dataset Aggregation） 的核心是：当前 student policy 访问状态，expert 对这些 student states 标注动作，数据聚合后再训练。它把监督覆盖扩展到 student 实际会遇到的状态，是有交互的监督式 imitation。Ross, Gordon & Bagnell 2011

经典 compounding-error 分析解释了这种采样变化为何有价值：早期动作造成的偏移会改变后续输入分布，回标让 student 练习这些偏移后的状态。实际恢复能力则通过 reward、coverage、model capacity 与真实 rollout 一起评估。

学习目标 / 数据采集 固定数据 跟随 learner 采新数据
拟合 expert action offline BC、VLA SFT DAgger 式回标与聚合
优化任务 return / 控制后果 offline RL、offline FB online RL、FB-CPR、BFM-Zero

数据采集方式与学习目标是两个可以交叉的分类轴。GAIL 等方法同时属于 IL 的问题设定和 RL 的求解路径；DAgger 则展示了交互数据怎样用于监督学习。

FB 学习 policy-dependent 长期后果，并用这些后果改进控制，将具体 downstream reward 延后给出，因此属于 RL 路线。RL 也有直接用 Monte Carlo returns 更新策略的方式，例如 REINFORCE。两者的共同点在于优化行动带来的回报，区别在于如何估计与利用这个学习信号。REINFORCE

9.3 RLT / EXPO 与 FB：state、action 与 task 接口

接口 latent 的含义 谁消费它 下游任务改变时
FB 的 z reward / goal / demonstration 的 task encoding 条件 actor，及 policy-conditioned F 重新推断任务向量，直接执行或另做适配
RLT 的 RL token VLA internal embeddings 的 compact state readout 小型 online actor / critic token 本身不自动提供通用 task-to-policy mapping
EXPO edit 对 base action candidate 的有界修正 executor 与候选 Q selection 为目标 reward 学 critic / edit，再按候选选择执行

RL token 提供 state interface，FB 的 z 提供 task interface。前者回答“当前是什么情况”，后者回答“现在要做什么”。RLT actor 接受 reference chunk 并受 reference regularization 约束，EXPO 则明确学习有界 action edit。按输入、输出与优化目标画接口，比按 latent 名称分类更清楚。RLT 课程精编 · S06 select + edit 讲义

这几条路线共享“估值是否可信、策略改进是否处于支持范围”的问题。RLT / EXPO 案例围绕已指定 reward 改善执行；FB 先预训练 task-conditioned representation，再给 downstream reward。Motion / safety regularization 又为这个可复用控制空间加入行为与物理先验。

9.4 什么时候值得尝试 BFM 接口

对 physics-based whole-body control，快速模拟器、proprioceptive state 与重定向 motion 让 RL 的长期控制学习较容易组织；对视觉丰富、接触复杂的 manipulation，action demonstrations 与 VLM prior 常提供有效起点。选择路线时，应从现有数据、模拟能力、任务变化方式与验证条件出发。

可研究的组合有：上层产生 task / reference，下层 BFM 执行；先 imitation 再 reward-based improvement；从无动作 human data 学表示或行为先验。每种组合都需要对齐状态、时钟与控制接口，再用 held-out rollout 判断它解决了哪个瓶颈。
