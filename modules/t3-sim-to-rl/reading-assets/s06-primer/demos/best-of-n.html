交互示例 · 一个 state 上的 best-of-N

固定一个 state。横轴是执行后的落点误差 x' = x + a，绿色带是成功区（±0.05）。蓝色阴影是 VLA 的采样密度（good mode 在 0，bad mode 在 +0.30）；绿线是真实成功概率；橙线是 critic 的评分，它在 VLA 很少采到的地方误差更大。只看一次决策，曲线来自解析函数，不训练网络。

● base 候选　◆ edit 候选（细线连回原候选）　◎ 被选中：上方是它的 critic 评分，下方绿点是它的真实成功概率

建议依次试：把 N 从 1 拉到 64；把 critic 误差调大，比较 single Q 与 min of 2 的"平均高估"；把 β 调大，看 edit 贴着上限的比例。
