## 本课符号表（温习速查）

- **causal mask**：(L,L) 下三角允许表，允许=1；被禁格在 S 里填 -1e9（不能乘）；**对角线必须是 1**
- **H / d_h**：头数 / 每头维度 = d/H；split 切的是**投影产出**的列，不是输入原料（W 每列吃全部 d 维）
- **W_O**：concat 后的混音矩阵——切 heads 不花钱，**混 heads** 才花钱（多头唯一新增参数）
- **Pre-LN block**：X ← X + mha(LN(X))，再 X ← X + ffn(LN(X))；residual 加的是 LN **之前**的裸 X
- **缩放**：多头 softmax 前除 **√d_h**，不是 √d

## ① 预测（任务书发布后锁定，3/3 命中）

- P1（H=1、W_O=单位阵退化版与 S01 一致）：**成立**——不分头=恒等切分、单位阵=不变换，管线退化回 S01 定义（含 √d_h→√d）→ ✅
- P2（causal 后 P 第 0 行 = [1,0,0]）：**成立** → ✅
- P3（causal 后 permutation equivariance 还在吗）：**不在**，"位置有关系了"——mask 按位置写死 → ✅

## ② 手算 / 自检

- causal 版 P 全表 + O 第 0/1 行：数值全对（[1,0,0] / [0.056,0.944,0] / 均匀行；O₀=自己的 V）
- **踩坑实录①**：S 第 1 行抄成第 0 行——shape、dtype 全对、行和=1 的**静默垃圾**；输出权重整行反转。防线 = 语义不变量：Q=K=V 时无 mask 的 P **对角线应为每行最大**，扫一眼即可抓
- torch 三连报错自力爬出：list 不能 `~` → `masked_fill` 拒收 long → dtype=bool 落地 `masked_fill(~m, -inf)`——S01 欠的张量语义债开始还
- 发现：softmax 对有限分数**永不判零**（e⁰=1，分数 0 也分走 5.6%）；真 0 只能来自 mask 的 -inf/-1e9

## ③ 追问记录

| 卡点 | 初答 | 最终理解 |
|---|---|---|
| 自回归（开课确认） | "自己 encode 到 next token" | 用序列自己的历史预测下一项，训练时 L 个位置并行各预测各的；causal mask 保证预测位看不见答案。"严格线性增长"表述留了尾巴：生成串行 ✓，计算成本是平方（S 表 L×L） |
| 首词孤独（追问1） | "自身 value，某种起点" | causal 下 token0 **每一层**都看不见别人，表示永远只是自己的函数 → BOS 锚点惯例；π0.5 图文前缀 prefix-LM 双向（待审 claim，挂 A3·S05） |
| 多头买到什么（追问2+自提"为何不重叠"） | 被 ASCII 密图挡住 | 单头每层只有一张注意力分布，多需求摊平互相稀释；H 张独立 P 并行 = 模式多样性。全维重叠头 = H 倍预算；均分槽位下 FLOPs 大头持平，**×H 的只有 softmax 元素数与 P 显存**（学员表述比 AI 的"基本持平"更精确） |
| 均分头维合理吗（自提） | "万一有些特征信息更多" | 均分的是槽位宽度，内容分配由投影训练自行决定（重要信息可同时流进多个头）；等宽才能 (H,L,d_h) 批量算 |
| W_O 价值（自提） | 课上没讲过 | concat 只是并排摆放、头与头各占各列互不往来；W_O = 可训练混音矩阵，让每个输出维成为所有头产出的线性组合 |
| Pre-LN vs Post-LN（追问3+反问"原版为何 Post"） | "防尺度不均衡"（Plausible-but-vague） | 分水岭 = identity path 是否被 LN 打断：Post-LN 的 LN 站主干道、深了要 warmup 伺候；Pre-LN 裸 X 直通到顶。历史：2017 沿 BN 时代惯例且模型浅不显，GPT-2 起 Pre-LN 成默认 |
| FFN 葫芦（追问4） | "更大空间表达再压缩" | 方向对；**命门是中间激活**——没有它两个线性层塌缩回 d×d。attention 唯一跨 token、FFN 原地加工（实验版证明见④） |
| Norm 三兄弟（自提） | "选项一是 LN？选项二是 BN？" | 两判皆对：LN=每 token 自己的 d 维、与 L 无关；BN=固定一维跨 batch 样本（依赖 batch 统计，序列推理靠不住）；RMSNorm=LN 砍减均值只除 RMS（S05 换装，Llama/Gemma 系在用） |

## ④ 实验与干预（P-T-I-E）

- 实现路径：[code/a1/s02_mini_decoder.py](../code/a1/s02_mini_decoder.py)——7 零件（causal_mask / split_heads / merge_heads / layer_norm / ffn / mha / block）全部由本人口述、AI 代笔，微测逐件验收；4 个关键决策（split 全部 QKV、√d_h、mask 在 softmax 前、三维批量）由本人拍板
- **踩坑实录②**：causal_mask 口述漏"等于"→对角线全 0 →全禁行被 -1e9 填满后三分数相等、softmax **均匀放行**——禁令全灭变放行，行和照样=1 的纯静默垃圾（-inf 版至少炸出 NaN）；证据抓获后本人口述修复
- 轴语义课：S01 的 softmax 写死 axis=1，3D (H,L,L) 时归一化到错误轴且行和照样=1；批量版须 axis=-1——**负轴才是"永远最后一维"的稳定说法**
- 检查结果：A 退化对拍 ✓ · B 眼罩生效（P 下三角/行和 1/第 0 行 [1,0,0]）✓ · C shape 链 ✓ · D 顺序实验：causal=False 等变保持、causal=True 等变破坏 ✓
- **三联对照实验**（只改 token3，看谁的输出动）：ffn `[F,F,F,T,F]`（原地加工）· mha 无 causal 全 True（全场交流）· mha causal `[F,F,F,T,T]`（**信息只向右流**——过去不动，现在与未来被波及；S04 KV cache 的机制红利）

## AI Claim Audit（现场抓获制）

- **Claim**："原始信息永远有一条直通车往上走……所以百层网络才训得动"。**质疑**（wayne）："一条"有语病——子层那条路不也在传信息？**裁定**：机制成立、表述歧义（"有一条"易读成"只有一条"）。**修正**：residual 是两条路并联（identity path + 加工路），输出为两者之和；identity path 的梯度系数恒为 1，才是"训得动"的机制。
