## 本课符号表（温习速查）

- **X**：输入矩阵，L 行 × d 列——L 个 token，每个是 d 维向量（本课 toy：L=3、d=2）
- **W_Q / W_K / W_V**：三个可训练投影矩阵，把 X 变成 Q / K / V（本课自检用单位矩阵，即"不变换"）
- **Q / K / V**：查询 / 索引 / 内容——同一份输入戴三副眼镜
- **S = Q·Kᵀ/√d**：L×L 相似度打分表；除 √d 防 softmax 饱和
- **P = softmax(S)**：按行归一化的注意力权重，每行和 = 1（注意：本课 P 指这个矩阵；预测仍叫 P1–P3）
- **O = P·V**：每个 token 按注意力权重对 V 加权取回的结果，L×d

## ③ 追问记录

| 卡点 | 我的初答 | 最终理解 |
|---|---|---|
| O 怎么算 | 先 `Ss * x`（逐元素乘）后 `Ss @ x`（对）但 dtype 报错 | `O=P·V` 是矩阵乘：每个输出行 = V 各行按注意力权重的加权组合；`*` 是逐元素乘完全不同。本次靠 shape 不合被拦下——若 L=d 会静默算出垃圾，shape 报错是朋友 |
| dtype 报错 | 不知如何处理 | 整数字面量建张量 → int64；与 float 矩阵乘会拒绝。修法 `.float()` 或写 `2.`。张量三查：shape / dtype / device |
| 彩蛋：第 3 行为何输出 [1,1] | "为什么刚好是它自己" | 两件事叠加：分数全等→权重均匀→输出=V 的平均（机制必然）；平均恰好=[1,1]（数字巧合）。O 每行 = 对应 token 查字典带回的结果 |
| ③问1：W_Q/W_K 共享 | "这样就成了 self attention？" | ✗ 两个独立的轴：self/cross 看 Q 与 K/V 来自哪（本 toy 全程是 self；DETR 的 cross 是 Q=object query）；共享权重则 S 被迫对称——注意力天生有方向。附加理由：Q≠K 打破对角优势（B 实验中 Q=K 时对角项致饱和） |
| ③问2：顺序敏感吗 | "不敏感，尤其 Q=K 时" | ✓ 精修：置换等变——输入行打乱、输出行跟着打乱、每个 token 的值不变；与 Q=K 无关。⇒ S02 必须外挂位置信息 |
| ③问3：L 翻倍成本 | "4 倍，可能 8 倍？" | ✓ 就是 4 倍（L²·d 项），投影仅 2 倍被淹没；罪魁 = L×L 的 S 表（prefill 开销收费处） |
| mask 怎么修 | "填极大负数…但又说乘" | ✓ 概念对：masked_fill / np.where(mask==0,-1e9,S)。必须填/加不能乘——负分数乘负大数会变正无穷，禁令变聚光灯 |
