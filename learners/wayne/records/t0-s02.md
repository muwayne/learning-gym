### B 组 · 单位灾难（force 列 raw×1000 跳过标准化）

预测判定：B1 早期 loss 差于 A **方向命中**（无爆炸尖刺，钉死 ln2——机制反转）；B2 force 梯度远大 **部分命中**（相对 40–300×，绝对值全体坍缩 <1e-4）；B3 Adam"接近有差距" **推翻**（一分未救）；加试 ×10"昏迷" **推翻**（带伤能学）。

**病理（本课最大一课）**：手算的无隐层世界发作为躁狂；tanh MLP 里 force×1000 把第一层全体按进 ±1 死区 → 每个样本同一张答题卡 → slip/pose 一并被没收 → 上层只能押底率 → loss=ln2 → tanh 斜率≈0 → 梯度集体归零，Adam 无米下锅。**同一病因，体质不同，症状相反：线性躁狂，tanh 昏迷；ReLU 则躁狂+局部猝死（换激活=换体质不治病，治病是 normalization）。剂量是相变不是渐变**（×1 健康 / ×10 带伤 / ×1000 昏迷；学员两次押注互贴错剂量标签）。×10 恢复时 w_f 不降反涨——优化器的救法≠人想象的治法。**病历句（学员 v2）**：梯度打进死区、几乎丢失 → loss 钉在纯猜；×10 未打穿、留有未饱和区间 → 优化器兜住但有代价。

### C 组 · 数据偏食（选项 c：重抽 90/10，测试集不动）

预测判定：loss 更低 **命中**（0.1471，且低于 0.20 地板——放回抽样重复样本可硬背，**有限考卷能钻到人群地板以下**）；unstable recall 0.5–0.7 **未命中窄差**（0.45）；σ 偏 stable **命中**（附加发现：中间质量 8.2%→39.6%，少数类边界学得潦草）。**病历句（学员）**：整体预测更容易了所以 loss 降；真实分布不一样所以没用（补：更容易=押多数类+硬背重复样本）。G2.0 对应：配比对账（stack 主动手 78/22 vs 50/50）+ 切片 recall。

### D 组 · 冻结纪律（requires_grad=False → 不入优化器清单）

Δ=**0.0000 恰等**通过（"小于预设值"收紧为恰等；阈值留给跨机 reload——G2.0 的冻结参数 hash 全等即此标准）。预测"明显变差>0.30" **未命中**（0.2827 小损档）。**机制**：**冻结≠摘除**——随机第一层仍是信息保真的非线性投影（16 个随机超平面切 3 维），上层学会在随机坐标系里干活；代价=收敛慢、更犹豫。类比校准：不是脑病变（会输出干扰），是"度数不对但没碎的眼镜"。"越深影响越小"记为可检验猜想。G2.0 对应：冻结 VLM 训 action expert 成立的最小原理；D0 的 prompt/遮挡反事实证明冻结骨干仍在传信息。

### E 组 · 容量瘦身（hidden=[2]，3-2-1）

预测判定：loss 0.35–0.40 **未命中窄差**（0.4428）；中间质量 ≈46% **命中**（50.4%，锚定 v2 外推）；软注"pose 先崩" **部分命中撞上分母课**——pose_edge/stable −25pp 重崩，但 force_edge/stable −28.6pp 略大，n=20–28 时一个样本值 5pp，**排序不可判**（= G2.0 "0/25 Wilson 上界 13.32%" 的 toy 版；小分母只能报"都崩了"，连续量才有信息密度）。**术语纠正**：E 组是**容量不足**（loss 尾部躺平仍高）不是**欠训练**（尾部还在降，S01 v1 是实例）；甄别=看尾部斜率+延长训练对照；recall gap 是定位工具不是火候工具。**病容**：loss 地板抬高、中间质量爆棚、全族普降边界族重灾。

## 补充教学（学员点名展开）

- **tanh 位置补课**：流水线图（加权求和→tanh 压扁 ×3 → 打分 z → σ 读数 → BCE），tanh=隐层激活/压扁函数（无它则四层线性=一层线性），σ 是表亲（压进 0..1 只在输出），BCE 在末尾；GELU/SwiGLU 同族现代款（A1·S05 换装）。
- **切片评估**：按 (边界族×类) 分桶 recall；总指标是平均数、平均数会藏尸；G2.0 的 per-task 表 / D0a 按 phase / 分层采样提案都是它；真实工作切片维度要自己造并记录（canonical strata）。
- **Grad norm 严谨版**：逐层 nₗ=‖∂L/∂θₗ‖₂；全局=√Σnₗ²（平方和开根→被最响层主导）；PI 面板只有一条因为它是 clip-by-global-norm 的副产品+逐层成本；开逐层=named_parameters 一行/JAX tree_map。**读图字典六病容**：健康/昏迷(B)/静音一路(D)/一枝独秀(5.8×)/驼峰(S01)/音量正常 loss 不动→换方向仪。
- **梯度余弦**：cos=⟨g_a,g_b⟩/‖g_a‖‖g_b‖；高维近正交是默认态（~1/√P），稳定负值才是干扰强信号；D0b 翻译="不打架但嗓门失衡"→处方是 norm balancing 不是 PCGrad。
- **迁移问答**（学员课末疑问）：方法层全迁移（G2.0 诊断本身就在用这些仪器）；病谱换脸——现代组件即疫苗（RMSNorm 治尺度绑架、残差治深层静音），病挪到无疫苗的新接口（任务配比、闭环分布、目标错位）；定量直觉不迁移，A1→A3 回真架构重验。

## ⑤ 固化

**三种效应总结（学员口述，Exit Gate 核心，AI 仅磨措辞）**：
- **优化几何（B）**：个别输入量级过大；排查=loss 卡住时看逐层音量表（全体塌方=链条被切）+ 查饱和度（G2.0 action-health 的 |a|≥1 即饱和体检）；
- **训练分布（C）**：训练分布与测试分布不同层面，训练太理想、实际不佳；排查=切片 recall + 配比对账（stack 78/22 vs 50/50）；
- **容量（E）**：网络装不下任务特征；loss 尾部躺平仍高、中间质量膨胀；排查=边界/切片 recall 看哪类学习明显偏差；
- **D 对照**：冻结随机层≠受伤——信息保真+上层适配，Δ=0 恰等是纪律。

**Revised mental model（学员认领）**：**"同一条 loss 曲线背后可能是优化几何、训练分布、容量三家不同的病；诊断不是盯总量曲线猜，而是先分诊——用逐层、切片、方向这些分解仪表把症状归到家，再用单变量干预验证。"**
