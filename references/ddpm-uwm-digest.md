## 一页总结（原笔记 §7 原样保留）

- 研究对象是不可见的分布 p，数据集是证据。E[·] 理论上对 p 算，实际对数据集算。
- `forward noising process` 是固定过程、无参数；`reverse denoising process` 是推断，唯一的可学习件是 s_θ。
- 闭式加噪 x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε：**timestep 是信息量旋钮**。
- 反向最优均值 μ 只依赖 E[ε|x_t]；网络学 E，μ 是采样端的换算公式。
- `conditioning` = 网络多一个干净输入；forward process 不变，E 及其派生物全部依赖 condition，因为**推断依赖证据**。
- UWM 的越界：让“干净还是加噪”由 timestep 决定，conditioning 和 marginalization 成为同一连续控制的两端。
- DDPM vs flow matching：谱系继承，非原理选择；flow matching 会让边缘化更严格。

## 符号速查（A2·S03 公式参考表的底稿）

总约定：**下标 t 是扩散步，不是物理时间**（UWM §III 同时出现物理时间的 o/o′ 与扩散步 t_a/t_o′，作者专门加脚注）。

| 符号 | 含义 | 谁在变 |
|---|---|---|
| x₀ ∼ p(x₀) | 干净样本；p 不可见 | — |
| β_t / α_t = 1−β_t | 第 t 步**单独**加噪方差 / 单独保留的信号比例 | 查表常数，不学 |
| ᾱ_t = ∏_{i≤t} α_i | **累积**保留的信号比例，1 → ≈0；最重要的量 | 查表常数 |
| x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε | closed-form noising；ε ∼ N(0, I) 是 t 步噪声的等效总噪声 | — |
| q(x_t \| x_{t−1}) | forward transition，由 β schedule 完全决定 | **无参数** |
| p(x_{t−1} \| x_t) | 真实反向转移，算不出 | — |
| p_θ = N(μ(x_t,t), σ_t²I) | 反向的参数化高斯 | θ 只藏在 μ 里的 s_θ |
| μ(x_t,t) = (1/√α_t)·(x_t − β_t/√(1−ᾱ_t)·E[ε\|x_t]) | 最优反向均值（Analytic-DPM），只依赖 E[ε\|x_t] | 固定公式 |
| s_θ(x_t, t) ≈ E[ε\|x_t] | **整个系统唯一被学习的东西** | θ |
| min_θ E_{x₀,t,ε} ‖s_θ(x_t,t) − ε‖² | 训练目标：分布学习 → 回归 | — |
| s_θ(x_t, z₀, t) | conditional 版本：z₀ 作**干净的**额外输入 | θ |

## 训练循环与采样循环（笔记 §4.2，A2·S03 ④ 段的实现规格）

```text
training step：抽 x₀、抽 t、抽 ε → closed-form 算 x_t → ε̂ = s_θ(x_t,t) → loss ‖ε̂−ε‖² → backprop
          全程没有 μ、没有逐步前向链、没有 p_θ
sampling loop：x_T ∼ N(0,I)；对 t=T…1：ε̂ = s_θ(x_t,t) → 公式算 μ → x_{t−1} = μ + σ_t·δ_t
```

训练学"看到噪声样本能猜出噪声"，采样用"猜出噪声就知道往回退到哪"；两端只靠 s_θ 一个网络连接。

## 追问索引（Q 编号供课程材料引用）

- **Q1 一步到位 vs 逐步加噪是一回事吗** — 是：独立高斯相加仍是高斯，均值相加、方差相加；训练不必跑前向链。闭式里的 ε 是合成总噪声，网络回归的正是它。
- **Q2 μ 是什么、何时用、与网络什么关系** — μ 是"从 x_t 往回退一步应退到哪"；右边除 E[ε|x_t] 全是已知量；网络不输出 μ，输出 ε̂，μ 由固定公式换算；**μ 只在采样时出现，训练时完全不出现**。"最优"= 在固定方差高斯假设下 MLE 意义的最优（Analytic-DPM），意义是把"学分布"约化为"学条件期望"。
- **Q3 两个核心直觉** — ①噪声水平 = 信息量的连续刻度：t=0 信息完整、t=T 信息为零；mask 是 {0,1} 的二值遮蔽，noise level 是 [0,1] 的连续遮蔽，mask 是它的两个端点。②学分布 = 学"从任何损坏程度指回数据的方向"：分布被隐式编码为向量场，**没有密度，只有方向**。
- **Q4 什么能当 condition、怎么进网络** — 任何能编码成张量且**推理时拿得到**的信息（观测、语言、动作、未来观测、本体 ID……）；t 本身从一开始就是条件，**从来没有无条件的 s_θ**。进网络的方式（AdaLN 调制 / cross-attention / 通道拼接 / in-context token）影响性能不影响数学。逆动力学 p(a|o,o′) 推理时 o′ 默认拿不到，得从别处供给。
- **Q5 条件化要改哪些式子** — **只改一处：网络多一个输入**。前向转移、闭式加噪不变；μ 形式不变、里面的 E 变成 E[ε|x_t, z₀]；训练期望改为对 (x₀, z₀) 成对取；采样每步把 z 一起喂。"a bulk of the machinery can be reused"。
- **Q6 为什么前向条件无关、E 却条件相关** — 前向是"物理"（撒沙子不关心照片里是猫是狗），反向是"推断"（答案取决于手里有多少证据）；E 本来就是条件期望，下标里放什么证据它就依赖什么。更精确：变的不是转移核 q(x_t|x₀)，是喂进机器的 x₀ 来自哪个先验，q(x_t|z₀) = ∫ q(x_t|x₀)·p(x₀|z₀) dx₀；条件多一个，后验更窄，条件期望的均方误差只会不增（全方差公式）；z 无信息时网络学会忽略它，**条件化最坏是无用，不会伤害**。
- **Q7 为什么扩散/流模型对机器人有价值** — 提供能拟合**多模态条件分布**的密度估计器：同一观测下"从左绕"和"从右绕"都合法，回归模型平均成穿中间（A2·S02 的 mode averaging），条件扩散能同时保留两个模式。Diffusion Policy = 条件 DDPM（z=观测，x=动作 chunk）；π0/π0.5 = 条件 flow matching（z=VLM 编码的图像/语言/本体，x=动作 chunk）；GR00T N1.7 同上加本体 ID。
- **Q8 UWM 对 §II-a 的越界** — 标准条件扩散里 z 永远干净、x 永远加噪，角色由架构定死；UWM 把"干净还是加噪"改由 timestep 决定：s_θ(o, a_{t_a}, o′_{t_o′}, t_a, t_o′)，t_a=0 时 a 是干净条件，t_a=T 时 a 被边缘化，中间是"部分条件"。**条件化和边缘化统一成同一旋钮的两端**；timestep 控制的是每个变量以多大程度进入 E 的证据集合。
- **Q9 DDPM vs flow matching（【评述】）** — 谱系继承非原理选择：UWM 建在 Diffusion Policy（DDPM，diffusers 默认 `squaredcos_cap_v2`、训练 T=100、DDIM 10 步）之上，π0 的 flow matching 晚于其实验定型「推断」。UWM 唯一依赖的性质是"端点 T 处样本不含 x₀ 信息"：flow matching 的 x_t = (1−t)x₀ + tε 在 t=1 **恰好**纯噪声，DDPM 的 ᾱ_T 只**近似**为 0（原文 "approximately an isotropic Gaussian"）——换 flow matching 反而更严格。后来者（DreamZero、Cosmos、LingBot-VA）全用 flow / rectified flow。工程差异：离散步数 + 方差调度 + DDIM 加速 vs 连续 t + 直线路径 + 更少步数。
